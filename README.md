# Pizza Sales Analysis — Power BI

## Project Overview
This project analyzes pizza sales data using Power BI to evaluate sales performance, understand product demand, and identify trends that can support business decisions.

## Business Objectives
- Evaluate overall sales performance using key performance indicators (KPIs).
- Identify top-performing and low-performing pizza products and categories.
- Analyze sales trends across days and time periods.
- Explore ordering patterns to identify opportunities for better sales planning.

## Tools & Technologies
- **Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — KPI calculations and measures

## Dataset
The project uses four CSV files:
- `orders.csv` — Order dates and order information
- `order_details.csv` — Pizza quantities and order-level product details
- `pizzas.csv` — Pizza prices, sizes, and product information
- `pizza_types.csv` — Pizza names, categories, and ingredients

## Key Performance Indicators
- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value

## Analysis Performed
- Revenue and order trends over time
- Sales performance by pizza type and category
- Product demand and ordering patterns
- Comparison of sales performance across products
